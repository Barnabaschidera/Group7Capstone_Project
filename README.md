# Group7App — Deployment Page

This folder contains a simple static webpage for the Group7App deployment.

Quick start

- Open [index.html](index.html) in a browser to view locally.
- To deploy online: push this repo to GitHub and enable GitHub Pages (Settings → Pages → Deploy from branch), or upload to any static host (Netlify, Vercel, etc.).

Files

- [index.html](index.html) — main page
- [styles.css](styles.css) — page styles
